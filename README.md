# Kipushku

Combien il reste à dépenser jusqu'à la paie : une appli web installable (PWA), pour le téléphone.

- **Aucune donnée ici.** Ce dépôt ne contient que le code. Les chiffres de chacun restent dans son téléphone
  (stockage du navigateur) et n'en sortent que dans une sauvegarde chiffrée par mot de passe (AES-GCM).
- **Sans serveur.** Le calcul et l'enregistrement tournent dans le téléphone ; l'appli marche hors connexion.
- Installer : ouvrir l'adresse de l'appli dans Chrome (Android), menu ⋮ ▸ *Installer l'application*.
